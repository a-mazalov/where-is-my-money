## Общая схема работы

```
┌─────────────────────────────────────────────────────────────────┐
│                         БАНК                                     │

└────────────────────────┬────────────────────────────────────────┘
                         │
                         │ SMS сообщение
                         ▼
┌─────────────────────────────────────────────────────────────────┐

└────────────────────────┬────────────────────────────────────────┘
                         │
                         │ Триггер автоматизации
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                  SHORTCUTS (КОМАНДЫ)                             │
│   • Автоматизация на получение SMS                               │
│   • Фильтр по отправителю                                        │
│   • Извлечение текста и отправителя                              │
└────────────────────────┬────────────────────────────────────────┘

                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                   SMSStorage (@Observable)                       │
│   • Хранилище сообщений в памяти                                 │
│   • Персистентность через UserDefaults                           │
│   • Автоматические обновления UI                                 │

                         │
                         │ Реактивное обновление
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                     ContentView (UI)                             │
│   • Список всех сообщений                                        │
│   • Детали каждого SMS                                           │
│   • Возможность ручного добавления                               │
└─────────────────────────────────────────────────────────────────┘
```

## Детальный поток данных

### 1️⃣ Получение SMS
```
Банк → iOS → Shortcuts Automation (триггер)
```

### 2️⃣ Обработка через Shortcuts
```swift
// Shortcuts автоматически передает:
{
    "smsText": "Покупка 1500.00 RUB Магазин ПЯТЕРОЧКА",
    "sender": "Сбербанк"
}
```

### 3️⃣ Вызов App Intent
```swift
ProcessSMSIntent.perform() {
    let message = SMSMessage(
        text: smsText,
        sender: sender,
        receivedAt: Date()
    )
    SMSStorage.shared.addMessage(message)
}
```

### 4️⃣ Обновление UI
```swift
// Благодаря @Observable, UI автоматически обновляется
ContentView → отображает новое сообщение в списке
```

## Модели данных

### SMSMessage
```swift
struct SMSMessage: Identifiable, Codable {
    let id: UUID           // Уникальный идентификатор
    let text: String       // Полный текст SMS
    let sender: String     // Отправитель (банк)
    let receivedAt: Date   // Время получения
}
```

### SMSStorage
```swift
@Observable
class SMSStorage {
    private(set) var messages: [SMSMessage] = []
    
    func addMessage(_ message: SMSMessage)
    func deleteMessage(_ message: SMSMessage)
    func clearAll()
    
    // Персистентность
    private func saveMessages()
    private func loadMessages()
}
```

## Особенности реализации

### Почему нельзя читать SMS напрямую?
iOS не предоставляет прямой доступ к SMS из соображений **безопасности и приватности**.

### Как работает решение через Shortcuts?
- ✅ **Официальное API** от Apple
- ✅ **Полный контроль пользователя** над автоматизацией
- ✅ **Работает в фоне** без открытия приложения
- ✅ **Безопасно** - данные не покидают устройство

### Преимущества App Intents
- 🔗 Интеграция с Siri
- 📱 Доступность из виджетов
- 🔄 Автоматизация через Shortcuts
- 🎯 Интеграция с Apple Intelligence (в будущем)

## Производительность

- ⚡️ **Мгновенное** сохранение SMS (< 100ms)
- 🔄 **Реактивное** обновление UI через @Observable
- 💾 **Эффективное** хранение через UserDefaults (будет Swift Data)
- 🎨 **Плавные** анимации с `.withAnimation`

## Безопасность

- 🔒 Все данные локально на устройстве
- 🚫 Нет отправки данных на сервер
- ✅ Пользователь контролирует автоматизацию
- 🔐 UserDefaults защищены песочницей iOS
