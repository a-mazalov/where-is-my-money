## 📝 Пошаговое тестирование

### Вариант 1: Ручное добавление (быстро)

1. Запустите приложение
2. Нажмите кнопку **"+"** или **"Добавить вручную"**
3. Скопируйте один из примеров выше
4. Вставьте отправителя и текст
5. Нажмите **"Добавить"**
6. ✅ Сообщение должно появиться в списке

### Вариант 2: Через Shortcuts (реальный сценарий)

1. Откройте **"Команды"**
2. Создайте новую команду (не автоматизацию, для теста)
3. Добавьте действие **"Обработать SMS"**
4. В параметр "Текст SMS" введите тестовое сообщение
5. В параметр "Отправитель" введите название банка
6. Запустите команду
7. Откройте приложение expenses
8. ✅ Сообщение должно появиться в списке

### Вариант 3: Полная автоматизация (финальный тест)

1. Настройте автоматизацию по [инструкции](SETUP_INSTRUCTIONS.md)
2. Попросите друга отправить вам SMS с текстом:
   ```
   От: [Имя друга] Банк
   Покупка 100 RUB Тестовая покупка
   ```
3. Подождите 1-2 секунды
4. Откройте приложение expenses
5. ✅ Сообщение должно автоматически появиться

## 🎯 Проверка функциональности

### ✅ Что должно работать

- [ ] Отображение пустого состояния при первом запуске
- [ ] Кнопка "Добавить вручную" открывает форму
- [ ] Кнопка "Настройка" открывает инструкции
- [ ] Форма добавления SMS принимает текст
- [ ] Новые сообщения появляются вверху списка
- [ ] Свайп влево показывает кнопку "Удалить"
- [ ] Кнопка "Очистить все" удаляет все сообщения
- [ ] Сообщения сохраняются после закрытия приложения
- [ ] App Intent вызывается из Shortcuts
- [ ] Время отображается в относительном формате ("2 минуты назад")

### 🐛 Возможные проблемы

#### Приложение не запускается
**Решение:** Проверьте версию iOS (требуется iOS 18+)

#### App Intent не отображается в Shortcuts
**Решение:** 
1. Пересоберите приложение
2. Перезапустите iPhone
3. Проверьте, что приложение запускалось хотя бы раз

#### Сообщения не сохраняются
**Решение:** Проверьте, что у приложения есть разрешения на запись в UserDefaults

#### Автоматизация не срабатывает
**Решение:**
1. Проверьте, что отключена опция "Спрашивать перед запуском"
2. Проверьте фильтры отправителя
3. Убедитесь, что автоматизация включена

## 🔍 Отладка

### Логи в Xcode
Запустите приложение из Xcode и смотрите консоль:

```swift
// При добавлении сообщения должно быть:
"Message added: <message_id>"

// При удалении:
"Message deleted: <message_id>"

// При очистке:
"All messages cleared"
```

### Проверка UserDefaults
В консоли Xcode выполните:
```swift
po UserDefaults.standard.data(forKey: "saved_messages")
```

### Проверка App Intent
В приложении "Команды" создайте команду и добавьте действие:
1. "Показать результат" → выберите "Обработать SMS"
2. Если действие найдено - интеграция работает ✅

## 💡 Советы по тестированию

1. **Начните с ручного добавления** - это самый быстрый способ проверить UI
2. **Затем тестируйте через Shortcuts** - убедитесь, что Intent работает
3. **Финально настройте автоматизацию** - проверьте полный flow
4. **Тестируйте на реальном устройстве** - симулятор не поддерживает SMS
5. **Сохраняйте тестовые сообщения** - создайте несколько для быстрого тестирования

## 📈 Метрики производительности

Ожидаемые значения:
- **Время добавления SMS:** < 100ms
- **Время обновления UI:** < 50ms
- **Размер одного сообщения:** ~200 байт
- **Максимальное количество:** ~10,000 сообщений (ограничение UserDefaults)
