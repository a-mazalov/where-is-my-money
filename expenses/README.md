# 💰 Expenses - Трекер расходов через SMS

iOS приложение для автоматического отслеживания расходов на основе SMS-сообщений от банков.

## ✨ Возможности

- 📱 **Автоматическая обработка SMS** через App Intents и Shortcuts
- 💬 **Отображение всех сообщений** от банков
- ➕ **Ручное добавление** SMS для тестирования
- 🔄 **Реалтайм обновления** при поступлении новых сообщений
- 📋 **Детальная инструкция** по настройке встроена в приложение

## 🚀 Что реализовано (Этап 1)

## 🛠️ Как настроить

### 1. Запустите приложение
Откройте проект в Xcode и запустите на реальном устройстве (симулятор не поддерживает SMS).

### 2. Настройте автоматизацию
1. Откройте приложение **"Команды"** на iPhone
2. Перейдите на вкладку **"Автоматизация"**
3. Нажмите **"+"** → **"Создать личную автоматизацию"**
4. Выберите триггер **"Сообщение"**
5. Настройте фильтр по отправителю (например: "Сбербанк")
6. Добавьте действие **"Обработать SMS"** из приложения expenses
7. Передайте параметры:
   - **Текст SMS**: "Содержимое сообщения"
   - **Отправитель**: "Отправитель"
8. ⚠️ **ВАЖНО**: Отключите "Спрашивать перед запуском"

### 3. Тестирование
- Добавьте SMS вручную через кнопку "+" в приложении
- Или попросите кого-то отправить вам тестовое SMS
- Или запустите команду вручную из виджета Shortcuts

## 🔒 Конфиденциальность

- Все данные хранятся **локально** на устройстве
- Приложение **не отправляет** SMS на внешние серверы
- Парсинг и категоризация работают **офлайн**
- Полный контроль над вашими данными
